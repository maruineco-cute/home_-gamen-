# スマホ画面メーカー

ステータスバーとコントロールセンター風の画面を組み立てて、PNG・JPGで保存できるWebツールです。
ビルド作業は不要で、`index.html` 1枚だけで動きます。

## できること

- 壁紙の画像を差し替え(ボタンの後ろにぼかして透けます)
- ステータスバー: 時刻、電池残量、電波、Wi-Fi・5G・LTE、充電中、低電力モード
- コントロールセンター: Wi-Fi・機内モードなどのオンオフ、音量・明るさのスライダー
- 再生中タイルの曲名、アーティスト、ジャケット画像の差し替え
- 下のアプリ列に、好きなアイコン画像を4つまで(丸 / 角丸)
- スマホ本体の枠(黒・銀・青)、カメラ部分(アイランド / ノッチ / なし)
- PNG・JPGで保存(PNGは枠の外が透明)

## GitHub Pagesで公開する

1. このフォルダの中身をリポジトリに入れます(`index.html` がリポジトリの一番上にあること)。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
4. 数分後に、表示されたURLでツールが開きます。

## メモ

- 画像はすべてブラウザの中だけで処理します。外部には送信しません。
- 文字のフォントだけ、Google Fonts から読み込みます(読み込めなくても動きます)。
- 画面は `<canvas>` に描いています。プレビューと保存画像は同じ描画です。
- これは非公式の見た目の再現です。Apple、iPhone、iOSなどは各社の商標です。ロゴは使っていません。
  作った画像を実際の画面と偽って使うことは避けてください。
